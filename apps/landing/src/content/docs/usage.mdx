# Usage Guide

## Creating a Project

1. Click **"New Project"** on the dashboard
2. Enter a name and description
3. Choose interview mode (Quick or Advanced)
4. Answer the questions
5. Click **"Generate Plan"**

## Interview Tips

- Be specific: "Next.js 15 App Router" not "React"
- Mention constraints: budget, compliance, performance
- Use concrete examples: "10,000 concurrent users" not "high traffic"

## Reviewing the Blueprint

After generation, the blueprint shows:
- **Phases**: Major project stages
- **Tasks**: Individual work items within phases
- **Dependencies**: What must be done before each task
- **Risks**: Identified potential issues
- **Execution Prompts**: Detailed instructions for each task

## Refining a Plan

If the blueprint needs adjustment:
1. Click **"Refine"** in the project view
2. Answer follow-up questions
3. A new plan version is generated

## Exporting

Download your plan as:
- **JSON**: Full structured data with all metadata
- **Markdown**: Human-readable document with all prompts
- **Task List**: Simple checklist of all tasks

## Settings

Configure in **Settings → Providers**:
- Add API keys for multiple providers
- Set default models per task type
- Enable/disable cost tracking
- Configure budget guardrails
