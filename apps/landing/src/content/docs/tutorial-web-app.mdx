# Tutorial: Build a Web App

This tutorial walks you through creating a complete web application from a raw idea.

## The Idea

Let's build a **personal finance tracker** — a web app that tracks income, expenses, and budgets with AI-powered insights.

## Step 1: Create Project

1. Click **"New Project"**
2. Name: "Personal Finance Tracker"
3. Description: "A web app for tracking income, expenses, and budgets with AI-powered insights"
4. Mode: **Advanced** (we want to cover everything)

## Step 2: Answer the Interview

Key questions and example answers:

**What's the core purpose?**
> Track personal finances with AI-powered spending insights and budget recommendations.

**What tech stack?**
> Next.js 15 App Router, PostgreSQL, Prisma, Tailwind CSS, shadcn/ui

**What's the user authentication model?**
> OAuth 2.0 with Google and GitHub. No password auth.

**What's the deployment target?**
> Vercel for frontend, Railway for database

**What are the data privacy requirements?**
> All financial data encrypted at rest. No third-party analytics. GDPR compliant.

## Step 3: Generate the Blueprint

Click **"Generate Plan"** and watch the progress:
- Synthesis (1–2s)
- Analysis (2–3s)
- Blueprint Generation (30–60s)
- Task Graph (1–2s)
- Prompt Assembly (5–10s)
- Summary (1–2s)

## Step 4: Review the Blueprint

The generated blueprint will include phases like:

1. **Setup & Configuration**
   - Initialize Next.js project
   - Configure database schema
   - Set up OAuth providers

2. **Core Features**
   - Transaction CRUD
   - Category management
   - Budget setting
   - Dashboard with charts

3. **AI Integration**
   - Spending pattern analysis
   - Budget recommendations
   - Anomaly detection

4. **Deployment**
   - Environment configuration
   - CI/CD pipeline
   - Monitoring setup

## Step 5: Export and Execute

1. Click **"Export"** → **Markdown**
2. Review the execution prompts
3. Start implementing tasks one by one
